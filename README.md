# Bank Management Application

## About the Project

The Bank Management Application is a simple C++ project that simulates basic banking operations. It allows users to create a bank account, deposit money, withdraw money, and check their account balance through a menu-driven interface.

I developed this project to practise object-oriented programming and understand how file handling can be used to save and manage customer account details.

## Features

* Create a new bank account
* Deposit money into an account
* Withdraw money from an account
* Check the account balance
* View account details
* Save account information using file handling

## Technologies Used

* C++
* Classes and Objects
* Object-Oriented Programming (OOP)
* File Handling

## How to Run the Project

**Step 1:** Install a C++ compiler, such as MinGW-w64.

**Step 2:** Open the project folder in VS Code.

**Step 3:** Open the terminal and compile the program:

```bash
g++ -std=c++14 bank_management.cpp -o bank_management.exe
```

**Step 4:** Run the application:

```powershell
.\bank_management.exe
```

**Step 5:** Choose an option from the menu and follow the instructions displayed on the screen.

## Data Storage

The application stores account details in a file named `accounts.txt`. This helps keep account information available even after closing the program and running it again.
